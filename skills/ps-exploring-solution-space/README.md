# ps-exploring-solution-space

Productside Exploring the Solution Space skill (Template 11).

## Files

- `SKILL.md` - skill definition, key concepts, application steps, pitfalls
- `template.md` - session plan scaffold with method catalog, quality checks, and post-session documentation
- `prompts/` - copy-paste prompts for chat-based AI tools, used in order
  - `README.md` - how AI supports this Play, traps, how to run the prompts, source notes
  - `01-scope-how-might-we.md` - test the PM's How Might We questions for scope (before the session)
  - `02-plan-ideation-session.md` - plan methods, ground rules, timeline, and hard moments (before the session)
  - `03-sharpen-solution-case.md` - benefits, risks, and value chain for the prioritized solution (after the session)
- `examples/sample.md` - strong, weak, and drift-bug examples with commentary
- `assets/ps_exploring_solution_space_playbook_pages.pdf` - source pages from the canonical playbook

## Notes

- Skill name uses the `ps-` prefix per project convention.
- This skill belongs to the **Discover + Define** phase.
- This is a **process skill** (`type: process`). The agent helps prepare a design thinking session; the actual ideation happens with the team in real time.
- Evidence gathering: this skill qualifies for **artifacts only**. The PM brings the validated problem statement, stakeholder alignment, and prior discovery work. No web research needed.
- The method catalog contains 10 tools from the Productside playbook organized across three activity types: Generating Ideas, Prioritizing Ideas, and Testing. A well-planned session includes at least one from each category.
- Upstream: ps-framing-the-problem (validated problem statement is required input), ps-empathy-interviews, ps-proto-persona, ps-jobs-to-be-done.
- Downstream: Solution Hypothesis Statement (the top idea from this session feeds the hypothesis).
