# ps-measuring-outcomes

**Template:** 22 of 24 | **Phase:** Deliver | **Type:** Component

Post-launch outcomes tracking dashboard that ties product and business outcomes to specific metrics, measurement tools, and baseline data.

## Files

- `SKILL.md` - skill definition, key concepts, application steps, pitfalls, references
- `template.md` - working scaffold with quality checks and capacity guidance
- `prompts/` - copy-paste prompt for chat-based AI tools
  - `README.md` - how AI supports this Play, traps, how to run the prompt, source notes
  - `01-grade-success-metrics.md` - grade the PM's success metrics; business results and survey scores go back for a rethink
- `examples/sample.md` - three examples: strong, weak, drift-bug (output vs. outcome inversion)
- `assets/ps_measuring_outcomes_playbook_pages.pdf` - source pages from the Productside Playbook canonical

## Notes

- Upstream dependency: ps-outcome-tree (Business Outcome and Product Outcome fields)
- Deliver-phase endpoint: no skills currently feed downstream from this one
- One product outcome per dashboard; multiple dashboards for multiple outcomes
- The two-table structure (Product Success Metrics / Product Health Metrics) is load-bearing - do not conflate the tables
- Baseline data is required before the dashboard is considered active
