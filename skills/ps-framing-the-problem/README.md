# ps-framing-the-problem

Productside Framing the Problem skill (Template 10).

## Files

- `SKILL.md` - skill definition, key concepts, application steps, pitfalls
- `template.md` - working scaffold with five-stem structure, context and constraints, final problem statement, and quality checks
- `prompts/` - copy-paste prompt for chat-based AI tools (authored for this library; the deck has no AI page for this Play)
  - `README.md` - how AI supports this Play, the common trap, how to run the prompt
  - `01-pressure-test-problem-frame.md` - pressure-test your problem frame
- `examples/sample.md` - strong, weak, and drift-bug examples with commentary
- `assets/ps_framing_the_problem_playbook_pages.pdf` - source pages from the canonical playbook

## Notes

- Skill name uses the `ps-` prefix per project convention.
- This skill belongs to the **Discover + Investigate** phase and marks a **Key Decision Point** at the intersection of Investigate and Define.
- The template produces a single artifact with three sections: Problem Framing (five stems), Context and Constraints, and Final Problem Statement.
- The five-stem sequence is fixed order: I am / Trying to / But / Because / Which makes me feel.
- Evidence gathering is **user artifacts only** - no web research offered. This skill synthesizes the PM's own discovery work.
- Upstream: ps-proto-persona, ps-jobs-to-be-done, ps-problem-identification, empathy interviews.
- Downstream: solution hypothesis, positioning, exploring the solution space (Discover + Define phase).
