# ps-tiny-acts-discovery

Skill for Tiny Acts of Discovery (Template 18, Create phase).

## Files

- `SKILL.md` - skill definition, key concepts, application steps, pitfalls, references
- `template.md` - working scaffold for the five-step exercise
- `prompts/` - copy-paste prompts for chat-based AI tools
  - `README.md` - how AI supports this Play, traps, how to run the prompts, source notes
  - `01-rank-assumption-backlog.md` - turn opportunities into assumptions; the PM scores impact and certainty
  - `02-design-tiny-act.md` - a wide range of tiny acts, narrowed to the fastest real signal; the PM picks
- `examples/sample.md` - three examples: strong, weak, drift-bug
- `assets/ps_tiny_acts_discovery_playbook_pages.pdf` - extracted playbook pages

## Notes

This is a **process skill**. The agent helps the PM plan and document the exercise. Steps 5 (running the tiny acts) happen in the field with real users, customers, or data. The agent does not conduct research or generate synthetic findings.

The skill applies at multiple lifecycle phases, not only Create. The playbook states explicitly: "This tool can be used in many phases of a product process or lifecycle."

Downstream connections: Outcome-Based Roadmap (Template 17) - specifically "Outputs to Develop," "Output Concepts to Validate," "Assumptions to Validate," and "Assumptions to Research" sections.

Related skill for single high-stakes assumptions: ps-lofi-experimentation (Template 14).
