# Stakeholder Alignment Prompts

**Source:** authored for this library. Not yet in the Productside Playbook. This Play is Template 02 of 24 in the B2B work-in-progress deck (slides 8-10), which has no AI page for it. The prompt follows the style of the deck's own AI prompts and apply its global rule.

This is a copy-paste prompt for working this Play in any chat-based AI tool. You don't need this skill installed to use it. If the skill *is* installed, it already behaves this way.

The Playbook's rule for every AI page: **you do the thinking, and AI pressure-tests it.**

## How AI Supports This Play

AI works here as a critic of the stakeholder map the PM drafted. It looks for stakeholders the PM missed, asks for the evidence behind each power and interest placement, and checks that each engagement strategy fits the quadrant. The placements and strategies stay the PM's, because only the PM knows these people.

| Use AI when | Avoid AI when |
|---|---|
| The PM has listed stakeholders and wants the map pressure-tested for gaps and placement. | The request is to characterize real colleagues' motives or influence from a name and a title. The model doesn't know them. |

**Outputs to expect:** missing stakeholder roles named for the PM to consider, each placement questioned against what the PM has observed, and engagement strategies checked against decision rights.

## Common Trap

**AI Places Stakeholders It Has Never Met.** The PM pastes ten names and titles and asks the agent to place them on the power/interest grid. The grid comes back filled in. Placements rest on job titles, not on how these people actually decide. The PM manages the wrong relationships.
